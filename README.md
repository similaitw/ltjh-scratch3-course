# Scratch 3 完整基礎課程網站

依「宜蘭縣 Scratch3 基礎課程 2022」系列主題重新整理的自學網站。

## 內容
- 14 堂主線課程
- 3 堂補充遊戲
- 2 堂視訊互動進階
- 知識技能地圖
- 每課：學習目標、核心積木、操作步驟、觀念、常見錯誤、延伸挑戰
- 本機學習進度紀錄（localStorage）
- 關鍵字搜尋
- 深色模式
- 手機版 RWD

## 執行
直接開啟 `index.html` 即可。

也可使用任一靜態網站伺服器，例如：

```bash
python -m http.server 8080
```

然後開啟 http://localhost:8080

## 部署到 Vercel
本專案為純靜態網站，可直接 Import 專案或拖曳整個資料夾部署。

## v2 課堂版新增

- 全課程技能檢核表：22 個可勾選檢核點，對應各課次。
- 每課學生任務卡：學習目標、獨立操作與延伸挑戰逐項勾選。
- 3 題即時小測驗：每課自動記錄上次成績。
- 教師模式：顯示教師驗收重點與未通過技能。
- 本機進度保存：課程完成、技能檢核、任務與測驗結果使用 localStorage 保存。
- 課程進度與檢核進度分開計算，適合課堂追蹤。

### 教師建議驗收流程
1. 學生先口頭說明本課規則。
2. 不看影片重新完成核心功能。
3. 任意修改一個數值或規則並說明影響。
4. 綠旗重跑至少兩次，確認初始化與結果一致。
5. 通過後再勾選全課程技能檢核表。

## v3 更新：影片逐步教學

- 目前透過固定版本的 ESM CDN 載入官方 npm 套件，部署時不需自行編譯；載入失敗時自動退回文字積木清單。
- 06～14、補充／進階課程將逐課補上官方積木組合。
- 操作位置說明仍規畫搭配 Scratch 官方編輯器實際截圖。
